recall@k–

Share of all relevant chunks that made it into the top k.

precision@k–

Share of the top k that is relevant.

reciprocal rank–

1 ÷ position of the first relevant chunk.

    Try it: set k to 1, then to 10. Recall climbs, precision falls. Then unmark the first result and watch only reciprocal rank collapse. The bench scores evidence phrases rather than chunks, so its recall can differ slightly.

          Three things to find: (1) at 5 per side the answer is 4th; at 6 per side it jumps to 1st, because now both lists contain it. (2) Set c to 0 and first place in either list dominates. (3) Move the weight to 0.3 and the fused list becomes dense alone.

          Separate, or together

          A bi-encoder turns the question and every chunk into vectors separately, so the chunk vectors can be computed before anyone asks. A cross-encoder reads the question and one chunk as a single input and returns one score.
